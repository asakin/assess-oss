# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-11-11

- `inspect`, `compare`, `search` and `alternatives` commands that return source-backed briefs for GitHub repositories, npm packages and Rust crates, with source links, dates and explicit unknowns.
- `profile` and `maintainers` commands for a person's public GitHub portfolio and for the owner, maintainers and contributors of a project.
- Agent Skill installation with `npx skills add asakin/assess-oss --skill assess-oss`, or with `assess-oss install-skill` from the npm package.
- Experimental `--jev` assessments of how well a project fits a stated goal, with `--dry-run` to preview the request.
